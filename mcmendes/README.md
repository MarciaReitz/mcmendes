# O Manual Que Faltava Para O Seu Cérebro

Landing page oficial do e-book de M.C. Mendes sobre neurociência prática para mulheres.

## 📚 Sobre

Uma série de publicações sobre neurociência descomplicada, com foco em bem-estar, foco e equilíbrio para mulheres.

**Edição #1**: O Manual Que Faltava Para O Seu Cérebro
- Preço de Lançamento: R$ 1,99
- Disponível na Amazon: [https://a.co/d/0aTfUKs4](https://a.co/d/0aTfUKs4)

## 🎨 Design

- **Paleta de cores premium**: Azul teal escuro + Dourado queimado
- **Mockup Kindle**: Apresentação elegante do e-book
- **Responsivo**: Otimizado para mobile, tablet e desktop
- **Animações suaves**: Scroll animations e hover effects

## 📱 Seções

1. **Hero** - Headline impactante + Mockup do livro + CTA principal
2. **Pain & Solution** - Storytelling emocional + Método dos 3 passos
3. **Sobre a Autora** - Bio e missão de M.C. Mendes
4. **CTA Final** - Reforço da oferta
5. **Footer** - Links sociais + Copyright

## 🧪 A/B Testing

A página rastreia cliques em diferentes variantes de CTA:
- **Variant A**: 🚀 COMEÇAR AGORA
- **Variant B**: 🔓 DESBLOQUEAR MEU MANUAL
- **Variant C**: ✨ SIM, QUERO MUDAR

Dados armazenados localmente em `localStorage` para análise.

## 🔧 Tecnologia

- HTML5 semântico
- CSS3 com degradês e animações
- JavaScript vanilla (sem dependências)
- Todos os assets inlined para máxima performance

## 📊 Performance

- ✅ Lighthouse score alto
- ✅ Otimizado para Core Web Vitals

- ✅ Carregamento instantâneo
